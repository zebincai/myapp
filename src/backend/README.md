# Backend

Python FastAPI backend for user CRUD APIs.

## API

The API is available under `/api/users`.

Supported operations:

- `POST /api/users`: create a user.
- `GET /api/users`: list users.
- `GET /api/users/{id}`: get one user.
- `PUT /api/users/{id}`: update one user.
- `DELETE /api/users/{id}`: delete one user.

Users contain `id`, `name`, `age`, and `job`. IDs are generated by the server.

## Development

Python tooling is defined in the root `pyproject.toml`. Run these commands from the repository root:

```sh
python -m venv .venv
. .venv/bin/activate
pip install -e ".[test]"
uvicorn backend.main:app --reload
```

By default, the backend stores data in `./app.db`. Set `DATABASE_URL` to use another SQLite database.

## Testing

```sh
pytest
```
